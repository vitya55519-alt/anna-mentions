# Лента упоминаний продукта

Telegram Mini App, который собирает в одну ленту:

- **упоминания продукта во ВКонтакте** — поиск по стене/новостям по ключевым словам (brand monitoring);
- **комментарии под собственными площадками** — комментарии из групп обсуждения Telegram-канала, где бот состоит.

Поиска по конкретным людям и какой-либо «оценки» сообщений в проекте нет — только агрегация упоминаний продукта и комментов под своими постами, чтобы удобно читать фидбек и отвечать.

## Архитектура

Один репозиторий → один проект Railway с двумя сервисами и базой:

- **web** — FastAPI: отдаёт мини-приложение (лента) и JSON API. Доступ к ленте защищён валидацией Telegram `initData`.
  `uvicorn app.web:app --host 0.0.0.0 --port $PORT`
- **worker** — Telegram-бот (long polling) + планировщик опроса ВК.
  `python -m app.worker`
- **Postgres** — общая база (Railway прокидывает `DATABASE_URL` в оба сервиса).

## Переменные окружения

| Переменная | Где нужна | Описание |
|---|---|---|
| `DATABASE_URL` | web, worker | строка подключения Postgres (от Railway) |
| `BOT_TOKEN` | web, worker | токен бота от @BotFather |
| `VK_TOKEN` | worker | токен доступа ВК для `newsfeed.search` |
| `VK_KEYWORDS` | worker | ключевые слова через запятую |
| `OWNER_IDS` | web | Telegram id владельцев через запятую (кому видна лента) |
| `POLL_INTERVAL` | worker | период опроса ВК, сек (по умолчанию 300) |

Сервисы поднимаются даже без заполненных токенов: соответствующий сборщик логирует, что ждёт токен, и не падает.

## Подключение мини-аппа

В @BotFather → Bot Settings → Menu Button (или через кнопку WebApp) указать публичный URL web-сервиса Railway.
Чтобы бот видел комментарии канала — привязать к каналу группу обсуждения, добавить туда бота администратором и выключить ему Privacy Mode в @BotFather.
